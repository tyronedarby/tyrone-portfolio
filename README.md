# Tyrone Darby — portfolio

A responsive, dependency-free portfolio built from the supplied résumé and profile illustration, following the workspace SKILL.md.

## Open locally

Open `dist/index.html` in a browser. All site assets are local; a build or package installation is unnecessary. For a local HTTP preview, run `node serve.mjs` and open http://127.0.0.1:4173.

## Edit

- Content: `dist/index.html`
- Design and responsive layout: `dist/styles.css`
- Mobile navigation and copy-email interaction: `dist/script.js`
- Profile and downloadable résumé: `dist/assets/`

Project illustrations are explicitly labeled and are not screenshots of the applications. Contact actions use email and the social URLs from the résumé. No form backend, analytics, or third-party scripts are used.

## Hosting

The deployable site is the `dist` directory. Sites identity and static output settings are stored in `.openai/hosting.json`. Sites publication defaults to private access.
