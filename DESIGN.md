# Design direction

Audience: engineering teams and recruiters evaluating Tyrone's Java backend work.
Purpose: understand his specialization, inspect relevant projects, and make contact.

Palette: ink #182345, paper #ffffff, lavender #eeedfa, iris #5750bb, muted slate #596477, line #dce1eb.
Type: Bahnschrift display headings with Segoe UI body; native sans-serif fallbacks keep the site independent of third-party font services.
Layout: generous left-aligned introduction paired with the supplied circular illustration; a single broad featured project, a compact secondary project, then experience and education.

    name                      navigation
    introduction              portrait
    actions                   caption
    specialization strip
    featured CRM / architecture diagram
    JavaFX project / task layout illustration
    experience                skills
    education                 certification
    contact

Review: avoided a generic dark developer template and repeated cards. The profile artwork carries the visual personality; the CRM diagram explains the actual resume-described stack. Project drawings are labeled as illustrations, not screenshots. No invented metrics, endorsements, or repositories.
